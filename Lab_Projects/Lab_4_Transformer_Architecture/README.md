# Lab 4: Transformer Architecture from Scratch

## Objective
Implement core components of the Transformer architecture.

## Tasks

### Required Tasks
1. Implement:
   - Self-attention mechanism
   - Multi-head attention
   - Positional encoding
   - Feed-forward layers

2. Visualize attention weights

3. Train a miniature Transformer on text classification

4. Analyze computational complexity

### Advanced Requirements
- [ ] Compare Transformer with BiLSTM
- [ ] Implement masking mechanism
- [ ] Analyze attention distributions
- [ ] Evaluate scalability

## Expected Outcome
Students should gain architectural understanding of modern NLP systems.

## Tools
- PyTorch
- Hugging Face
- NumPy
- Matplotlib

## Deliverables
- [ ] Attention visualization (`attention_viz.py`)
- [ ] Custom Transformer code (`transformer.py`)
- [ ] Experimental report (`REPORT.md`)
- [ ] Complexity analysis (`complexity_analysis.py`)

## Dataset
- AG News or custom classification dataset
