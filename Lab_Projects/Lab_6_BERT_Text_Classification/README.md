# Lab 6: Fine-Tuning BERT for Multi-Class Text Classification

## Objective
Fine-tune Transformer-based language models for advanced NLP tasks.

## Tasks

### Required Tasks
1. Use Hugging Face Transformers library

2. Fine-tune BERT for:
   - Sentiment analysis
   - Fake news detection
   - Spam detection

3. Implement:
   - Tokenization
   - Attention masks
   - Learning rate scheduling

4. Evaluate using:
   - Accuracy
   - Precision
   - Recall
   - F1-score

5. Compare BERT with classical ML models

### Advanced Requirements
- [ ] Hyperparameter optimization
- [ ] Error analysis on misclassified samples
- [ ] Adversarial input testing
- [ ] Compare BERT, RoBERTa, and DistilBERT

## Expected Outcome
Students should gain expertise in industrial-grade NLP pipelines.

## Tools
