# Lab 5: Distributional Semantics using word2vec, GloVe, and FastText

## Objective
Analyze semantic representation learning using distributional semantics.

## Tasks

### Required Tasks
1. Train custom word embeddings using:
   - CBOW
   - Skip-Gram

2. Load pre-trained:
   - word2vec
   - GloVe
   - FastText embeddings

3. Perform:
   - Word similarity analysis
   - Analogy tasks
   - Semantic clustering

4. Visualize embeddings using:
   - PCA
   - t-SNE

### Advanced Requirements
- [ ] Compare subword modeling
- [ ] Evaluate embeddings on downstream tasks
- [ ] Analyze semantic drift
- [ ] Perform multilingual embedding comparison

## Expected Outcome
Students should understand semantic representation learning mathematically and experimentally.

## Tools
- Gensim
- Scikit-learn
- Matplotlib
- NumPy
