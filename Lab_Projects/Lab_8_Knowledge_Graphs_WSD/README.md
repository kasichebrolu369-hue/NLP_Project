# Lab 8: Knowledge Graphs and Word Sense Disambiguation

## Objective
Implement semantic understanding systems using lexical databases.

## Tasks

### Required Tasks
1. Use WordNet for semantic relation extraction

2. Implement Lesk Algorithm for Word Sense Disambiguation

3. Build semantic similarity system

4. Compare:
   - Knowledge-based methods
   - Embedding-based methods

### Advanced Requirements
- [ ] Hybrid semantic similarity model
- [ ] Context-aware WSD
- [ ] Domain-specific ambiguity resolution
- [ ] Graph-based semantic visualization

## Expected Outcome
Students should understand semantic ambiguity handling in NLP.

## Tools
- NLTK WordNet
- NetworkX
- Matplotlib
- NumPy

## Deliverables
- [ ] WSD implementation (`word_sense_disambiguation.py`)
- [ ] Semantic graphs (`graph_visualization.py`)
- [ ] Comparative report (`REPORT.md`)
- [ ] Semantic similarity system (`semantic_similarity.py`)

## Dataset
- SemEval datasets for WSD
- WordNet corpus
